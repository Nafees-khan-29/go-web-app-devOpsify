before you post

The questions that come up every week

"My docker-compose won't start."

Almost always a port conflict or a missing depends_on. Check the pinned thread first.

"Terraform state is out of sync."

Common after a manual console change. There's a walkthrough for safely re-importing state.

"Which cloud should I learn first?"

AWS if you're job-hunting broadly, Azure if your target companies already run on it.

"A pod is stuck in CrashLoopBackOff."

Start with `kubectl logs --previous`. Nine times out of ten, the answer is in there.
